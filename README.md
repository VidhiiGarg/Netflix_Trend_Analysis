# Netflix Content Trends & Viewer Insights Through Data Visualization 

In this project, I explore and uncover patterns hidden inside the Netflix dataset using data visualization techniques. The analysis focuses on understanding the type of content available on Netflix and identifying trends in movies and TV shows through visual storytelling.

The dataset (netflix_titles.csv) contains information about Netflix titles, including:

Basic Details: Title, type (Movie or TV Show), director, cast, and description
Release Information: Release year and date added to Netflix
Categorization: Ratings, genres, and listed categories
Production Details: Country-wise content production and distribution trends

As streaming platforms continue reshaping the entertainment industry, data analysis helps reveal how audiences consume content and how platforms like Netflix curate their libraries globally. This project provides insights into the evolution of digital entertainment through data-driven exploration.

## Key Questions Explored

Are Movies or TV Shows more dominant on Netflix?
Which words appear most frequently in Netflix titles?
Which countries contribute the highest number of titles?
What is the average duration of Netflix movies?
Which genres are most common on the platform?

## Methodology

The objective of this project is to practice exploratory data analysis and visualization using real-world datasets. Different visualization techniques are used to interpret trends and patterns effectively, including:

Scatter Plots
Histograms
Box Plots
Bar Charts
Word Clouds

The project uses Python libraries such as:

Matplotlib
Seaborn
WordCloud
Pandas
NumPy
